# UI-переработка панели: аккордеон групп + прогрессивное раскрытие

**Дата:** 2026-07-28 · **Статус:** утверждено пользователем (брейншторм с мокапами)

## Проблема

Вкладка «Инструменты» — 14 карточек одной простынёй, накопленных по хронологии добавления фич. Порог входа вырос, нужное находить тяжело. Верх вкладки «Чат» перегружен кнопками.

## Решение (утверждённые выборы)

1. **Навигация**: аккордеон по смысловым группам (выбран из 3 мокапов: аккордеон / чипы / workflow-лента).
2. **Параметры**: прогрессивное раскрытие — главное видно, тонкая настройка в спойлере (выбран из 2 мокапов).
3. **Объём**: вкладка «Инструменты» полностью + лёгкие правки чата. Структуру чата не трогаем.
4. **Подход реализации**: ре-парентинг на месте — карточки переносятся в контейнеры групп в `index2.html` **с сохранением всех ID**; логика panel.js не меняется. Аккордеон/спойлеры — небольшой новый JS + CSS поверх.

## 1. Структура «Инструментов»

Верхняя панель закреплена над аккордеоном (как сейчас): «⚡ Анализ аудио», LED состояния, чекбокс «Только In/Out».

Группы (порядок фиксирован):

| Группа | Карточки (существующие id) |
|---|---|
| 🧹 Чистка речи | card-silences, card-fillers, card-profanity, card-jumpcuts, card-trim-edges, card-gaps |
| 🎥 Мультикам и спикеры | card-multicam, card-speakers |
| 🎬 Рилс и субтитры | card-reels |
| 📑 Структура ролика | card-chapters, card-markers-export |
| 🔧 Сервис | card-loudness, card-backups |

Разметка: `.tools-group` → `.tools-group-head` (эмодзи, название, счётчик инструментов, стрелка ▸/▾) + `.tools-group-body` с перенесёнными карточками. Точные id карточек сверить с DOM при реализации (таблица выше — по названиям; фактические id могут отличаться, например card-markers-export).

**Удаляется**: мёртвая карточка «🎬 J-cuts / L-cuts» (`card-jcuts`, задизейблена `pointer-events:none`, кнопка «Недоступно»). Перед удалением проверить, что JS-обвязка терпит отсутствие её элементов (jcut-offset уже отсутствует в DOM и код это переживает).

## 2. Аккордеон

- Открыта ровно одна группа; клик по заголовку другой — предыдущая сворачивается, клик по открытой — сворачивает её (все закрыты — допустимо).
- Последняя открытая группа запоминается в `localStorage` (`extllmpr_v1_tools_group`). Дефолт первой загрузки — «Чистка речи».
- **Авто-раскрытие**: если инструмент из свёрнутой группы показал proposal, результат или ошибку — его группа раскрывается автоматически (результат не должен потеряться с глаз). Реализация: хелпер `toolsRevealCard(cardId)`, вызываемый из существующих точек показа proposal/ошибок; альтернатива — MutationObserver, но явные вызовы проще и предсказуемее.
- Механика — чистый JS/CSS (класс `.open` на группе), без сторонних библиотек. ES5-синтаксис (CEP-браузер старый Chromium — сверить с текущим кодом panel.js, он ES5-стиль).

## 3. Спойлеры «⚙ Тонкая настройка»

Для тяжёлых карточек — блок `.tool-advanced`: заголовок-строка «⚙ Тонкая настройка (N)» + сворачиваемое тело. Состояние каждого спойлера в `localStorage` (`extllmpr_v1_adv_<cardId>`), дефолт — закрыт.

| Карточка | Остаётся видимым | Уходит в спойлер |
|---|---|---|
| 🔇 Тишины | темп-пресет, waveform, кнопка запуска | режим среза, мин. пауза, порог+Авто, паддинг до/после, crossfade |
| 🎥 Мультикам | источники, кнопка | все Tier-слайдеры и тумблеры |
| 🎬 Рилс | виральные моменты (пресет, длина, поиск), кнопки сборки | настройки субтитров (анимация, шрифт, цвета, размер) |

Остальные карточки — без спойлера (1–2 параметра, прятать нечего). Перенос параметров в спойлер — тоже ре-парентинг с сохранением ID.

**Нюанс waveform**: canvas в скрытой группе имеет нулевые размеры — при раскрытии группы/спойлера дёргать существующую перерисовку (если waveform уже посчитан).

## 4. Тексты карточек

Заголовки и `tool-card-desc` всех карточек переписать по **фактическому** поведению функций (сверка с deterministic-pipelines.js / host, как делалось для тултипов filler-mode). 1–2 строки, без обещаний, которых код не выполняет. Существующие тултипы (title/param-row) сохраняются.

## 5. Чат (лёгкие правки)

- «Откат маркеров» (`btn-undo` + `undo-popover`) переезжает внутрь попо­вера «Ещё» — те же ID, обработчики не трогаем. Проверить позиционирование вложенного поповера.
- Бейдж токенов (`usage-badge`) — компактнее по CSS.
- Больше в чате ничего не меняется.

## 6. Что НЕ делаем

- Не меняем ни одного ID существующих элементов и ни одной строки логики инструментов.
- Не переписываем вкладку с нуля, не реорганизуем из JS (отвергнутые подходы 2 и 3).
- Не трогаем структуру чата, композер, стартеры.
- Не добавляем новых функций.

## 7. Тестирование

1. `node --check` на panel.js (и новый JS аккордеона), `npm test` — 1008 тестов без изменений логики должны пройти как есть.
2. CDP-скрипт: снять полный список ID элементов вкладки «Инструменты» ДО перестройки, сверить ПОСЛЕ — ни один не потерян (кроме намеренно удалённого card-jcuts).
3. CDP live: аккордеон переключается (одна открыта, память в localStorage), спойлеры открываются/помнят состояние, авто-раскрытие при ошибке/proposal.
4. Smoke живьём: 2–3 инструмента конец-в-конец (например «Убрать тишины» до proposal, бэкапы, «Найти мат»), waveform перерисовывается после раскрытия.
